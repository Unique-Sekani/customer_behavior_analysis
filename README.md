# Customer Behavior Analysis

## Overview

This project analyzes customer data to identify behavioral patterns, purchasing trends, customer segments, and factors that influence customer engagement and spending.

The project demonstrates an end-to-end data analytics workflow, from data preparation and exploratory analysis to SQL querying, dashboard development, reporting, and presentation of business insights.

## Objectives

* Understand customer purchasing behavior and preferences
* Identify trends and patterns within customer data
* Analyze customer demographics and spending habits
* Segment customers based on behavioral characteristics
* Generate actionable business insights
* Present findings through an interactive dashboard and report

## Project Workflow

### 1. Data Loading

The dataset was imported into Python using Pandas for initial inspection and preparation.

### 2. Data Cleaning

The data was examined and cleaned by:

* Handling missing values
* Removing duplicate records
* Checking data types
* Identifying inconsistent values

* Preparing the dataset for analysis

EDA was performed to understand customer behavior and identify important trends.

The analysis examined areas such as:

## How to Run

### Python Analysis

1. Clone the repository.
2. Install the required Python libraries.
3. Place the dataset in the `data/` folder.
4. Open the Jupyter Notebook.
5. Run the analysis cells sequentially.

Example:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

Then:

```bash
jupyter notebook
```

### SQL Analysis

1. Import the dataset into your preferred SQL database.
2. Open the SQL file in the `sql/` folder.
3. Execute the queries against the database.
4. Review the resulting analysis.

### Power BI Dashboard

Open the `.pbix` file using Power BI Desktop and refresh the data source if necessary.
